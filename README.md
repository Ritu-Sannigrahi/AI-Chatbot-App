# 🤖 Smart AI Chatbot App

A simple, fast, and easy-to-use Android Chatbot application built using Kotlin. This app connects with Groq API to answer user questions instantly in a clean chat interface.

---

## 📌 Project Overview

This app works like a personal assistant. Users can type any question or message, and the app gets an intelligent response from Groq AI and displays it on the screen inside chat bubbles.

---

## ✨ Main Features

* **Fast AI Replies:** Get quick and smart answers to your questions in real time.
* **Simple Chat Interface:** Clean design with custom chat bubbles for user messages and AI responses using RecyclerView.
* **Safe & Secure:** Uses API key placeholders so private credentials remain fully protected.
* **Smooth Performance:** Lightweight design for quick loading and smooth navigation.

---

## 🛠️ Tools & Technologies Used

* **Programming Language:** Kotlin
* **User Interface:** Android XML Layouts
* **AI Service:** Groq API
* **Development Platform:** Android Studio
